# Участие в разработке проекта StashIt

Мы приветствуем ваш вклад в развитие проекта экосистемы Kobalt Tools!

## Принципы разработки
1. Всегда сохраняйте легковесность приложения (потребление памяти < 25 МБ).
2. Используйте Svelte 5 с рунами (`$state`, `$derived`, `$effect`).
3. При изменении публичных возможностей обновляйте сайт на Flutter Web в папке `website/`.
4. Создавайте понятные Pull Request с описанием изменений.
