# Политика безопасности (Security Policy)

Экосистема Kobalt Tools уделяет первостепенное внимание приватности и безопасности локальных данных пользователя.

## Поддерживаемые версии
Только последняя мажорная версия утилиты поддерживается обновлениями безопасности.

## Сообщение об уязвимости
Если вы обнаружили проблему безопасности, пожалуйста, создайте приватный отчет через GitHub Security Advisories или свяжитесь с автором через профиль @kobaltgit.
